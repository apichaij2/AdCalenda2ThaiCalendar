# AdCalenda2ThaiCalendar

@file:   README.MD<br>
@Project:   AdCalenda2ThaiCalendar<br>
@Licese:    Open source and licensed under MIT license.<br>
@Language:  Google Apps Script (JavaScript)<br>
@Author:    Apichai Jantarmas (apichaij2@gmail.com)<br>
@Version:   1.0<br>
@Date:  18-October-2025<br>
@Descriptions:  Translate date from Anno Domini (A.D.) to Thai Calendar date.<br>
<br>
@Function NAME:  AdCalenda2ThaiCalendar(ADdate)<br>
input:  ADdate = Date Object<br>
<br>
Limitation year: ( Between A.D. 1857 - 2156 )<br>
ข้อจำกัด:  สามารถ แปลงค่าได้ ตั้งวันที่ ๑ มกราคม ระหว่าง พ.ศ. ๒๔๐๐ - สิ้นปี ๒๖๙๙ (ค.ศ. 1857 - 2156)<br>
<br>
output: Thai Calanda date "วันพฤหัสบดีที่ ๑ เดือนมกราคม พ.ศ. ๒๕๔๗ ขึ้น ๑๐ ค่ำ เดือนยี่(๒)<br>
    1. วัน: "จันทร์ อังคาร พุธ พฤหัสบดี ศุกร์ เสาร์ อาทิตย์"<br>
    2. วันที่: 1...31<br>
    3. เดือน: "มกราคม กุมภาพันธ์ มีนาคม...ธันวาคม"<br>
    4. ข้างขึ้น/ข้างแรม: ขึ้น ๑ ค่ำ... ขึ้น ๑๕ ค่ำ / แรม ๑ ค่ำ... แรม ๑๕ ค่ำ<br>
    5. เดือน(ไทย): "เดือนอ้าย เดือนยี่ เดือนสาม...เดือนสิบสอง"<br>
    6. พ.ศ.: ๒๔๐๐ - ๒๖๙๙<br>
    7. ปีปีนักษัตร: "ชวด ฉลู ขาล เถาะ มะโรง มะเส็ง มะเมีย มะแม วอก ระกา จอ"<br>
<br>
