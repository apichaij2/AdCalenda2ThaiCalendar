@Descriptions:  Translate date from Anno Domini (A.D.) to Thai Calendar date.

@Function NAME:  AdCalenda2ThaiCalendar(ADdate)
input:  ADdate = Date Object

Limitation year: ( Between A.D. 1857 - 2156 )
ข้อจำกัด:  สามารถ แปลงค่าได้ ตั้งวันที่ ๑ มกราคม ระหว่าง พ.ศ. ๒๔๐๐ - สิ้นปี ๒๖๙๙ (ค.ศ. 1857 - 2156)

output: Thai Calanda date "วันพฤหัสบดีที่ ๑ เดือนมกราคม พ.ศ. ๒๕๔๗ ขึ้น ๑๐ ค่ำ เดือนยี่(๒) 
    1. วัน: "จันทร์ อังคาร พุธ พฤหัสบดี ศุกร์ เสาร์ อาทิตย์"
    2. วันที่: 1...31
    3. เดือน: "มกราคม กุมภาพันธ์ มีนาคม...ธันวาคม"
    4. ข้างขึ้น/ข้างแรม: ขึ้น ๑ ค่ำ... ขึ้น ๑๕ ค่ำ / แรม ๑ ค่ำ... แรม ๑๕ ค่ำ 
    5. เดือน(ไทย): "เดือนอ้าย เดือนยี่ เดือนสาม...เดือนสิบสอง"
    6. พ.ศ.: ๒๔๐๐ - ๒๖๙๙
    7. ปีปีนักษัตร: "ชวด ฉลู ขาล เถาะ มะโรง มะเส็ง มะเมีย มะแม วอก ระกา จอ"
